## 🔬 Projects That Tell a Story

<br/>

### 🛒 `ga4-checkout-funnel` — Where do users disappear before buying?
> **BigQuery · GA4 · Looker Studio · SQL**

Modeled a full 6-step e-commerce funnel — view → cart → checkout → shipping → payment → purchase — entirely in BigQuery's public GA4 dataset. Sized mobile vs. desktop drop-offs and quantified the revenue left on the table. Built an experiment backlog: 5 A/B tests ranked by expected lift.

**The punchline:** A 5pp checkout improvement on 10K sessions at $80 AOV = **+$40,000 revenue recovered.**

[![→ View Project](https://img.shields.io/badge/→%20View%20Project-302b63?style=flat-square)](https://github.com/trisha2103/ga4-checkout-funnel)

---

### 💉 `GlucoGuard` — Diabetes risk prediction for everyone, not just clinicians
> **Python · scikit-learn · Streamlit · CDC BRFSS · joblib**

Trained a calibrated ML classifier on 38K+ CDC survey records. ROC-AUC: **0.82**. Deployed as a Streamlit app with a live threshold slider so users — not algorithms — decide the sensitivity/specificity tradeoff. Complete with confusion matrix, PR curve, and ROC outputs.

**The punchline:** Democratising early-risk screening beyond clinic walls, with full ethical transparency built in.

[![→ View Project](https://img.shields.io/badge/→%20View%20Project-302b63?style=flat-square)](https://github.com/trisha2103/Diabetes-Risk-Prediction---Gluco-Guard)

---

### 📉 `subscription-revenue-retention` — What does 4% monthly churn actually cost?
> **Python · PostgreSQL · Docker · Tableau · SQL cohorts**

Full-stack analytics pipeline: Python ETL → Dockerised PostgreSQL → SQL cohort analysis (logo retention, revenue retention, MRR waterfall) → Tableau executive dashboards. Quantified churn at customer-level and modelled intervention scenarios.

**The punchline:** Cutting churn 10% = 20 customers saved/month × $300 MRR × 6 months = **$36,000**.

[![→ View Project](https://img.shields.io/badge/→%20View%20Project-302b63?style=flat-square)](https://github.com/trisha2103/subscription-revenue-retention)
